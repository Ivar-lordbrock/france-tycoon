# Outils du duo

Le plus simple : double-clique sur **`0-ouvrir-les-outils`** (ou sur le raccourci « France Tycoon » du Bureau). Une fenêtre avec de gros boutons s'ouvre et pose les questions une par une. Vidéo de 3 minutes : [docs/medias/fenetre-des-outils.mp4](../docs/medias/fenetre-des-outils.mp4).

Sinon, double-clique sur les fichiers numérotés, dans l'ordre de ta journée :

| Fichier | Ce que ça fait |
|---|---|
| `0-ouvrir-les-outils` | Ouvre la fenêtre des outils (tous les boutons). |
| `1-installer-mon-poste` | Installe et vérifie ton poste (une fois, puis quand tu veux). |
| `2-mettre-a-jour` | Récupère le dernier `dev`. |
| `3-commencer-une-tache` | Crée ta tâche depuis le dernier `dev`. |
| `4-envoyer-mon-travail` | Enregistre et envoie ton travail sur GitHub. |
| `5-proposer-mon-travail` | Ouvre la proposition vers `dev`. |
| `6-ou-j-en-suis` | Montre où tu en es. Ne change rien. |
| `7-fusionner` | Fusionne une proposition aux vérifications vertes. |
| `8-fin-d-etape` | `dev` vers `main` et version (propriétaire). |

Les mêmes actions existent dans Claude Code : `/mettre-a-jour`, `/commencer`, `/envoyer`, `/proposer`, `/ou-j-en-suis`, `/fusionner`, `/fin-d-etape`, et `/relire` pour relire le travail du binôme.

Guide pas à pas : [docs/07-travailler-a-deux.md](../docs/07-travailler-a-deux.md). Le moteur est dans `moteur/`.
